# Python Day 125 - Average of List Numbers

This Python program calculates the average of numbers stored in a list.

## Example

Numbers:
```text
[10, 20, 30, 40, 50]
```

Output:
```text
Sum: 150
Average: 30.0
```

## Concepts Used

- Python lists
- `sum()` function
- `len()` function
- Variables
- Division operator `/`

## How It Works

The `sum()` function calculates the total of all numbers in the list. The `len()` function counts the number of elements. The program divides the total by the number of elements to calculate the average.
